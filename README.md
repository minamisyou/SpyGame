# NIGHT ECHO

**스플린터 셀 감성의 2D 잠입 액션** — 브라우저에서 바로 돌아가는, 빌드 도구 없는 순수 HTML/CSS/JavaScript 게임입니다.
그림자에 숨고, 시야원뿔을 피하고, 조명을 쏘아 어둠을 만들고, 흔적 없이 빠져나가세요.

> A top-down stealth infiltration game for GitHub Pages. No build step, no dependencies,
> no binary assets — every sound is synthesised and every pixel is drawn on a canvas.

## 🕶️ 게임 규칙

- **빛이 곧 위험** — HUD의 `LIGHT` 게이지는 지금 당신이 얼마나 잘 보이는지를 나타냅니다.
  게이지가 바닥이면 경비의 시야원뿔 안에 서 있어도 거의 발각되지 않습니다.
- **조명은 파괴할 수 있습니다** — 천장 등에 마취탄을 쏘면 방 전체가 어두워집니다.
  단, 유리 깨지는 소리는 멀리까지 들립니다.
- **소리는 벽을 넘습니다** — 달리면 발소리가, 병을 던지면 큰 소음이 퍼지고 경비가 그쪽을 조사하러 갑니다.
- **제압은 비살상** — 뒤에서 `E`로 기절시키거나 마취탄을 명중시킵니다.
  단, **쓰러진 동료를 다른 경비가 발견하면 경보가 올라갑니다.**
- **경보 3회 = 임무 실패.** 발각되면 시야에서 벗어나 숨으세요.
  경비가 마지막 목격 지점을 수색하다 포기하면 경계가 풀립니다.
- 목표: **모든 데이터 단말 해킹 → 탈출 지점(EXIT) 도달.**

무발각·무제압으로 클리어하면 **GHOST** 보너스와 함께 최고 랭크 `S`를 받습니다.

## ⚙️ 기술 노트

빌드 파이프라인 없이 ES 모듈만으로 구성했습니다. 핵심 시스템은 다음과 같습니다.

| 파일 | 역할 |
|---|---|
| `src/raycast.js` | DDA 그리드 레이캐스팅 — 시야 판정, 가시성 폴리곤, 타일 라이트맵 |
| `src/pathfinding.js` | 이진 힙 A* + 스트링 풀링 경로 평활화 |
| `src/guard.js` | 경비 AI 상태 기계 (순찰 → 의심 → 조사 → 경계 → 수색) |
| `src/level.js` · `src/levels.js` | ASCII 맵 파서와 레벨 데이터 |
| `src/render.js` | 레이어 합성 렌더러 (월드 → 조명 multiply → 시야원뿔 → 전장의 안개) |
| `src/audio.js` | WebAudio 절차적 효과음 — 오디오 파일 0개 |

**조명 모델.** 각 조명은 로드 시 한 번 가시성 폴리곤을 계산해 두고, 렌더링 때 그 폴리곤으로
클리핑한 방사형 그라디언트를 가산 합성합니다. 게임플레이용으로는 타일 단위 라이트맵을 따로
계산해 두고, 플레이어 노출도는 그 값을 이중선형 보간해서 구합니다. 조명이 파괴되거나 문이
여닫히면 두 자료구조 모두 다시 계산됩니다.

**전장의 안개.** 매 프레임 플레이어 위치에서 360° 방향으로 200개의 광선을 쏘아 가시성
폴리곤을 만들고, 이를 `destination-out`으로 어둠 레이어에 뚫어 시야를 표현합니다.
벽 뒤는 실제로 보이지 않습니다.

### 로컬에서 실행하기

ES 모듈은 `file://`에서 동작하지 않으므로 정적 서버가 필요합니다.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

### 레벨 검증

맵은 손으로 그린 ASCII입니다. 검증 스크립트가 격자 크기, 외벽 밀폐, 순찰 노드 참조,
목표 도달 가능성(키카드가 잠긴 문 뒤에 있지 않은지 포함)을 확인합니다.

```bash
npm run validate     # 또는 node tools/validate-levels.mjs
```

### 새 레벨 추가하기

`src/levels.js`에 항목을 하나 추가하면 됩니다. 맵 기호는 다음과 같습니다.

```
#  벽          .  바닥        =  강화유리 (통과 불가 / 시야·빛은 통과)
D  문          +  잠긴 문     *  천장 조명      C  보안 카메라
@  시작 지점   X  탈출 지점   I  데이터 단말
A  마취탄      B  병          K  키카드
0-9 a-z        순찰 경로용 이름표 (그냥 바닥 타일입니다)
```

경비는 `route: ['0', '1', '2']`처럼 이름표를 순서대로 순찰합니다.
카메라 설정 배열은 맵에 나타나는 `C`의 순서(위→아래, 좌→우)와 짝지어집니다.

## 🚀 GitHub Pages 배포

이 저장소에는 Pages 배포 워크플로가 포함되어 있습니다. 최초 1회만 설정해 주세요.

1. **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 변경
2. 브랜치에 푸시하면 워크플로가 자동으로 사이트를 배포합니다
   (`.github/workflows/pages.yml`, 수동 실행도 가능)

또는 Actions 없이 **Deploy from a branch** 를 골라 브랜치와 `/ (root)` 를 지정해도 됩니다.
저장소 루트에 `.nojekyll` 이 있어 Jekyll 처리 없이 그대로 서빙됩니다.
